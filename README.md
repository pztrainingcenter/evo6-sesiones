# Sesiones EVO-6 · PZ Training Center

Este repositorio lo actualiza Claude cada semana al generar las sesiones EVO-6 con la skill.
La app "Mi progreso EVO-6" (www.pztrainingcenter.com/progreso/) lee de aquí las sesiones
de cada semana (`sesiones/`), y el script de Google «PZ EVO-6 · PDF a Drive» copia los PDF
de `pdf/` a Google Drive › EVO-6.
**No borres ni renombres este repositorio** y déjalo **público**: solo contiene las sesiones y
sus PDF, ningún dato de clientes.
